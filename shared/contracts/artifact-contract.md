# Artifact contract

## Before the answers

* **Allowed:**
  * `.m-edit/` control files
  * transcript data
  * `transcript.md`
  * `direction.md` (the questions)
* **Forbidden:**
  * cuts
  * Remotion compositions
  * downloaded assets
  * previews or finals

## While directing

* **Allowed:**
  * `video_editing_guide.md`
  * `.m-edit/edit.json` and its audit report
  * organized assets and the asset ledger
  * Remotion code and props
  * stills
  * versioned previews for every clip, each with its verification, contact sheet and hash-locked recipe
  * one stitched review file
  * `reel_review.md`

## After the whole-video approval

* **Allowed:** one final-quality render per clip, each compared with its approved preview and recorded with its verification.
* **A merged file** only after a separate explicit request.

## Naming and location

* Everything generated stays inside the project, under the configured output root.
* Never overwrite a source clip.
* Version previews; never replace an approved file in place.

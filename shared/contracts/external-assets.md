# External-asset contract

Prefer, in order:

1. user-provided assets
2. self-created Remotion graphics
3. official product assets used for identification, commentary, or instruction
4. public-domain, CC0, or appropriately licensed assets

Network access is off by default. Do not download media, fonts, models, packages, logos, or music unless the user said yes in the questions (or later in chat), or the config pre-approves it (`assets.allow_free_licensed_downloads`).

Never use watermarked media, ripped creator footage, unlicensed songs, film/television clips, or unverified brand marks by default. Avoid remote URLs during render.

For every external asset, record source URL or origin, retrieval date, author/provider, license or usage basis, original filename, local path, and clips where it appears. If rights are unclear, use a generated graphic or text label instead.

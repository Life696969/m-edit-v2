# Approval-language contract

Record the user's exact words as evidence in `.m-edit/approvals.jsonl`.

## Answers to the questions

Any reply that answers the questions counts:

* "go"
* "all good"
* "use your picks"
* a numbered list of changes
* a mix of these

A question back from the user is not an answer. Answer it, then wait.

## Whole-video approval

Approval clearly accepts the preview that is currently under review:

* "approved"
* "render the finals"
* "looks great, finalize"
* the same in any language

## Never approval

* a change request ("make the title bigger"): revise, show the review again, and STOP
* "okay", "nice" or an emoji, when it is unclear what is being accepted
* silence, elapsed time, or approval of something else

After any change, the changed preview needs review again.

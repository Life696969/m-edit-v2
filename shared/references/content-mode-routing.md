# Content-mode routing

Choose one primary mode from the transcript, visuals, and user brief. Add `mixed` only when no single mode explains most of the edit.

| Mode | Strong signals |
|---|---|
| talking-head | one or more speakers address the camera; speech carries the value |
| tutorial-screencast | interface actions, steps, cursor, code, or screen legibility are central |
| podcast-interview | conversational exchange, remote/local guests, questions and answers |
| product-demo | a product, workflow, feature, or before/after result must be proven visually |
| montage-cinematic | mood, sequence, music, movement, and visual storytelling carry the edit |
| slideshow-image | still images, documents, screenshots, or cards are the primary media |
| mixed | two or more modes materially alternate and need explicit handoffs |

Record the selected mode and evidence in `transcript.md` and `video_editing_guide.md`. Do not choose a mode only because it is trendy.

# Mixed-format mode

Use mixed mode only when two or more primary modes materially alternate, such as talking head plus tutorial, podcast plus product demo, or montage plus narration.

## Plan

- Name each segment's primary mode and transition point.
- Define a shared typography, caption, color, and motion system across modes.
- Preserve orientation when switching between speaker, screen, product, and b-roll.
- Let each segment use the rules of its primary mode rather than averaging them into one generic treatment.
- Use explicit handoffs: crop transition, audio bridge, layout change, or visual cue.
- Keep caption placement responsive to each format.

## Common failures

- switching styles without a shared system
- tiny screen recordings inside a talking-head layout
- using montage pacing during detailed instruction
- hiding speaker reactions for too long

## Review

A viewer should always know what they are seeing, why the mode changed, and where to look next.
